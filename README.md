# 经济学随笔

 

 与人交流的想法要随时记录，注意对现实的观察和直觉。做些小文章也好，增加对社会运行规律的理解；在此基础上，如能做些大文章，使用主流的研究方法，则更加有益于他人。

 我始终没有想好，究竟要怎么开始，严格意义上来说，或许已经开始了。我是在25年的时候，就有了这么个想法，要写一点东西，写一点对于宏观经济现实观察的思考，至于对这个东西的定位，我却一直拿不准，一个比较确定的事，就是那不能是严肃、刻板的学术"八股文"，但是也不能是随行就市、直言直行的流水账和笔记，这其中的“度”就比较难把握。我想，它应该是一个“小品”文，里面应该有一些现实的刻画，更重要的是应该有一些思考，或许是浅显的、甚至是错误的、荒唐可笑的，但是我想这都不要紧，要紧的是头脑要有些思考。

写这么一个系列是个费力不讨好的事，尤其是在现在生成式人工智能大行其是的时候，一字一字地写东西似乎变得很廉价。“博通经史食无鱼，士如敝帚尚自珍”，自己当然没那么大的学问，但是每餐都还吃的起鱼，只要想的话，但是文章确实总是以为自己的好，哪怕事实并非如此，只是情感使然，故而“文如敝帚犹自珍”，我想这也没什么，人之常情而已，重要的是当自己写的一点东西被他人弃如敝履的时候，自己能做到“不以物喜，不以己悲”才好，倘若起心动念，言语造作，那说明修身的功夫还不到家，那正是修行时候。

既然是个性价比不高的事情，为什么还要做呢？在学界有句话比较流行“idea is cheap”，但是在现在这个时候，好像想法变得格外有价值。每个人的精力都是有限的，不可能事事涉猎，否则可能只是浅尝辄止，但是自己又是一个喜欢胡思乱想的人，我想将这些想法和思考记录下来，或许今后再也用不到这些想法，再也不会进一步地深入研究，这对自己来说算是个交代吧。自然界有自然界的运行规律，人类社会有人类社会的运行规律，想要认识和掌握自然界的运行规律已是不易，想要认识和掌握人类社会的运行规律则更是困难。在纷繁的现实世界中，提出一点真知灼见，对认识和改造现实世界有些许意义，那就足慰平生了。开普勒在提出三大定律之前，牛顿在《自然哲学的数学原理》之前，都写过一些所谓的“大杂烩”的东西，陶哲轩认为正式这些奇奇怪怪的思考造成的思维“涌现”的现象，才最终成就了那些自然科学的基本原理。这可能就蕴含着思考本身的价值，哪怕最终没有从中得到某些有价值的东西，思考本身对预防老年痴呆也有其积极意义。
